# flow-apps

XDG .desktop registry (locale, OnlyShowIn, Hidden), shell-free Exec tokenising and field-code expansion, frecency, launch with child reaping, per-app permission state (camera, microphone, location, notifications, background, storage).

**Status:** Implemented and tested.
