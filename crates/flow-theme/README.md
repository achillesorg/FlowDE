# flow-theme

Interface themes (liquid-glass, minimalist, material-you, anthropic-design), liquid-glass material resolution with accessibility/ambient/content/motion adaptation, quality governor, icon packs and per-app overrides, GTK CSS/CSS-vars/flat token outputs, D-Bus `org.flowde.Theme1`.

**Status:** Logic fully unit tested; no rendering was performed.
